# Railway Reservation System

A Railway Reservation System built using Python and MySQL.

## Features

- Train Booking
- Ticket Cancellation
- Train Search
- Fare Details
- Ticket Details using PNR
- Seat Availability
- Railway Analytics
  - Popular Routes
  - Revenue Analysis
  - Gender Ratio
  - Age Distribution
  - Bookings by Date

## Technologies Used

- Python
- MySQL
- Matplotlib
- Pandas

## Requirements

pip install matplotlib pandas mysql-connector-python

## Run

python railway.py
